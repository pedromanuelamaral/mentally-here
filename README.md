# Mentally Here

This started as a personal `Safety Plan` mental health tool that now aims to be a `broader companion project` for your own mental health journey. **But why exist or try?**

> "'Pain is hard to bear,' he cried, "But with patience, day by day, even this shall pass away." (Theodore Tilton)

In days of struggling with my own mental health and searching for a safety plan app but disliking the products I found. In realising that one of my own ways of coping and finding life worth living was to "Create something I care about”, I forced myself to build something to get through another day.

### SAFETY PLAN

Personal and offline-first (mental health/suicide prevention) Safety Plan interface for you.

**Sections inside:**
- Warning signs
- Coping strategies
- Emotional support contacts
- Professional support contacts
- Comfort places
- Quick checklists by location
- Reasons to live

**Quick Guide:**
1. Download `safety-plan.html`
2. Open it in your browser
3. Edit with your own information
4. Click "Download file" to save it locally
5. Open the downloaded file, tap Share to save it locally

**How it works:**
- Single Safety Plan file in `.html`
  - Editable in the browser with data saved
  - Download and use offline and in private
  - Data lives/stored inside the file on export
  - Vanilla JS. No dependencies

# FITNESS HUB

A private, self-hosted, single-file web app that acts as a fitness hub inside this mental health companion project.

**Contents inside:**
- Broad video library, +122 videos, 10 categories and intents
- Curation of audio (Music and Audiobooks)
- Session packaging (Workout + Audio + Recovery)
- Calendar and To-Do integration
- Quick checklists by location
- Reasons to live

**How it works:**
- Single `.html` file for the entire web app
  - Vanilla JS. No dependencies.
  - Any browser. No account or tracking.

**Quick Guide:**

1. **Open the app:** Double-click `index.html` in any browser or open via `file://`.
2. **Host anywhere (optional):** Deploy as a static site on any web server or hosting service.
3. **Keyboard Shortcuts:**
   - Press `/` to focus the search bar from anywhere (auto-expands library if collapsed).
   - Press `Esc` to dismiss any active modal.
